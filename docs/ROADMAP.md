| # | 缺口 | 现状 |
|---|---|---|
| 1 | **Docker 部署** | 无 Dockerfile/compose，私有化部署仅 pm2/systemd，首装门槛高 |
| 2 | **SSE 中途状态推送** | 现 SSE 仅回「已受理」，上游拿不到接单/完成/驳回的中途事件 |

## 三、体验断点诊断（为什么还不是「体验很好的软件」）

按全链路找断点，**最伤体验的是接入层**：

- **接入（对 agent/开发者）**：异步受理 + 手动轮询，无回调 webhook、无中途 SSE → 「零代码接入」打折，开发者心智负担重；无 tools，agent 能力表达受限。
- **交互一致性断裂**：任务 = 异步轮询（小时级），审批 = 同步挂起（分钟级）——设计各自合理，但上游要理解两套契约。
- **使用（对工程师）**：工作台桌面单页、移动端弱 → on-call 接单不及时；SLA 有倒计时无（前端不展示 deadline）；超时靠人盯。
- **治理（对管理员）**：RBAC 粗糙、审计不可配置、合规证明不可导出（仅 JSON）。
- **部署运维**：无 Docker、无监控、无备份 → 私有化落地摩擦大、数据安全底气不足。
- **商业化**：无计费 → SaaS 无法按量收费；无租户报表/PDF 报告 → 企业采购审核缺材料。

## 四、三阶段路线（带验收标准）

### 阶段 A「体验筑基」（1–2 月）

1. Docker 一键部署（compose + 镜像 + .env 模板）→ 验收：`docker compose up` 一条命令跑通 PG + app
2. SSE 中途推送 + 完成回调 webhook → 验收：上游收到接单/完成事件，无需轮询
3. tools / function calling → 验收：agent 传 `tools` 人类可执行并返回 `tool_calls`
4. 工作台补：SLA 倒计时 + 哈希链可视化 + 模板工单
5. 移动端 PWA + on-call 值班 + 通知升级序列
6. 备份脚本 + 恢复演练 + Prometheus `/metrics`

### 阶段 B「企业就绪」（2–4 月）

7. 企业 SSO（OAuth2 先行，再 LDAP/企微/钉钉）
8. 细粒度 RBAC（三权分立落地）+ 审计配置化
9. 计费计量（人力成本核算 + 租户账单）
10. 合规报告 PDF / 定时 / 订阅导出
11. 多工程师负载均衡自动派单

### 阶段 C「生态与变现」（4–6 月+）

12. FDE 入驻 + 结算（能力市场）
13. 产出回流标注 → 私有评测集闭环（数据飞轮）
14. AgentOps / OTel 对接 + LangChain/AgentTeams 官方示例
15. SKILL / AGENT 模板市场
16. 托管 SaaS 上线（变现起点）

## 五、开源变现长期规划

### 模式：Open Core（开放核心）

- **核心（MIT 免费，守住「永久免费」承诺）**：现有全部能力——网关、治理基础、多租户、i18n。
- **企业版（付费）**：SSO、细粒度 RBAC、合规报告导出、SLA 告警升级、备份、技术支持。

> 选型理由：竞品网关（coai / clawrouter 等）均走 open core；本项目用户本就私有化导向，企业版价值清晰；核心免费做流量、企业版做收入。

### 四条变现路径（按现金流速度排序）

1. **托管 SaaS**（最快）：已有多租户（`upstream_key` 路由），几乎零改造成本 → 按任务量/工程师数订阅。
2. **企业私有化 LTS 授权**：Docker + 企业版功能 + 技术支持，按年——面向「数据不出网关」刚需客户。
3. **FDE 能力市场抽成**（护城河）：工程师挂牌 → 平台撮合 → 按成功任务抽成。这是「FDE 平台化」理念的自然延伸，网络效应最强（人越多网关越值钱）。
4. **数据飞轮**（合规前提）：只卖脱敏的 general 级任务模板/标注集，**绝不碰涉密**（`audit.js` 已有涉密仅 admin 门禁可复用）。

### 关键洞察与护城河

本项目最独特的护城河不是「又一个 LLM 网关」，而是**「人」作为可治理、可留痕、可计费资源的调度基础设施**。变现叙事应主打「把人的产能变成可按需调用的企业资产」，而非「AI 网关」——后者红海，前者空白。

### 风险与对策

| 风险 | 对策 |
|---|---|
| 涉密合规 | 严格隔离，能力市场只做 general 公开级，涉密数据物理隔离 |
| 「人工可扩展性」质疑 | 用数据飞轮证明 AI 兜底边界，人只做 AI 做不了的 |
| 变现与开源承诺矛盾 | 企业版只收增值，不动 MIT 核心 |
