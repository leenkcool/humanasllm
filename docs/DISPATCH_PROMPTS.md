# 可派单提示词（20 条）

> 用途：在 Claude Code / Codex / OpenCode / WorkBuddy / Cursor 等 AI Agent 里输入以下提示词，Agent 会通过 `human-llm` 模型把任务派给 P390 人工工程师。
> 提示词末尾可附 `category`（confidential/ops/general），涉密/运维类锁死不 AI 兜底。

## 一、合规 / 备案（confidential）
1. 请IT大神帮我做网站备案规划，包含 ICP 备案、公安网安备案、所需材料清单与时间线。
2. 请帮我整理等保三级建设方案，含差距分析、整改项、测评流程与预算估算。
3. 请帮我完成微信小程序的备案材料准备与提交流程说明。
4. 请帮我做生成式 AI 大模型备案与算法备案的合规评估。
5. 请帮我审计当前系统的 SSL 证书与域名解析配置，列出到期风险和续费计划。

## 二、数据库 / 运维（ops）
6. 请帮我评估并制定生产库 MySQL→PostgreSQL 迁移方案，含停机窗口与回滚策略。
7. 请帮我排查数据库慢查询，定位 TOP10 慢 SQL 并给出索引/改写优化建议。
8. 请帮我制定数据库每日备份与异地备份方案，含恢复演练步骤。
9. 请帮我巡检服务器磁盘/CPU/内存/带宽使用，输出健康报告与扩容建议。

## 三、安全（confidential）
10. 请IT大神帮我做一次授权范围内的渗透测试，输出漏洞清单与修复建议。
11. 请帮我排查疑似入侵事件：分析日志、定位攻击源、给出应急响应与加固方案。
12. 请帮我制定服务器主机基线安全加固清单（口令/端口/补丁/权限）。

## 四、密钥 / 权限（confidential）
13. 请帮我盘点服务器账号与 SSH 密钥，制定轮换与最小权限方案。
14. 请帮我梳理第三方模型密钥与 API 网关令牌的保管与轮换机制。

## 五、机房 / 物理环境（ops）
15. 请帮我制定机房巡检规范，含温湿度、防火、电力、UPS 检查项与应急流程。
16. 请帮我规划新机柜/服务器上架方案，含布线、IP、端口分配。

## 六、部署 / 上线（ops）
17. 请帮我制定新版本灰度发布与回滚方案，含环境区分（开发/测试/预发/生产）与验证步骤。
18. 请帮我搭建 CI/CD 发布流水线并处理首次配置问题（含失败排查）。

## 七、规划 / 文档（general）
19. 请IT大神帮我撰写一份团队工时与资源规划报告，评估当前任务的负载与优先级。
20. 请帮我整理一份项目上线前的自查清单（功能/性能/安全/合规/备份）。

---

## 使用方式
1. 把上面任意一句输入你的 AI Agent（如 Claude Code）。
2. Agent 识别为需人工/涉密任务 → 调 `human-llm` 路由 → 返回 `task_id`。
3. 人工工程师在工作台接单完成 → Agent 回查取回产出。

> 涉密/物理/合规类任务系统自动定级 confidential/ops，**绝不交给公有大模型**。
